Glossary and codes

TermMeaning
Sister locationA location of the same dealership grouped with others for stock sharing; the session refers to a first set of locations, a second set of sister locations and an overall sister set (S01 03:50).
Excess stockStock at a location above what that location needs to keep; the system shows at which locations excess is lying so it can be transferred rather than re-ordered (S01 04:45). Two calculations are used: at a partner location in inter-location case (b), see "Excess (location)"; at a child location of a mother, see "Excess stock at child".
Internal transferMovement of material from one location of a dealership to another, as an alternative to ordering from the company.
ClusterA grouping of locations to which a common transfer rule applies; shown as a second table on the Add New Setting screen.
GainerA co-dealer from whom parts may be purchased; "Gainer Stock Check" on the screen asks whether such stock is considered.
Moving / Non-moving / Non-stockableStock-quality classes of a part at a location, used as a condition in transfer and cluster rules (S02 04:17, Figure 8.3.1b rows).
Free stockStock at the buying location not reserved against any job; if free stock is available the system can auto-reject a purchase with the remark "Issue From Stock" (S02 11:37-12:12).
Rule typeThe family a rule belongs to on the Add New Rule page, e.g. Gainer (purchase from a co-dealer); selects which parameters are offered (S02 12:36-12:55).
ParameterA value the rule engine can test; parameters are created from the columns of an uploaded brand file and from values derived from them (S02 13:53-15:25).
StoreA stock-holding unit within a location; a location may have several stores and the upload can include or exclude each (S02 14:46-14:52).
Multi-login filesSeparate downloads from a brand portal, one per login (per model, segment or location), that together make one data type for a dealer; Mahindra gives seven such logins (S03 04:04-08:08).
Readiness viewA screen listing, per dealer, whether all the files that dealer needs have been uploaded and validated, so that order generation can be started for those that are complete (S03 15:33-18:02).
Child location switchesThe "include stock of child location" and "include max of child location" options on the Order Generate screen (Figure 9.3.1a).
OGYS / OGSOrder Generation System – the Sparecare module whose rule settings this document covers. Both spellings appear in the workbook.
OOQThe quantity already on order and not yet received for a part at a location. Standard formula: Pending Purchase Orders + Pending In-Transit + Pending Stock Transfer Receipts (S04 06:38). The full form of the abbreviation was not stated – see OI-020.
SOQSuggested Order Quantity – the quantity the system proposes to order: MAX − Current Stock − OOQ + CBO (S04 04:59, 05:57).
MAXMaximum stock level defined for a part at a location (from the Dealer MAX / inventory-levels file).
POPurchase Order placed on the company (OEM).
Pending PO (PPO)Purchase-order quantity not yet received: PO − MRN − STN Pending as spoken (S04 00:59) – see OI-021 for the sign conflict with the workbook.
MRNMaterial Receipt Note – receipt of ordered material; the workbook distinguishes MRN Done and MRN Pending.
STNStock Transfer Note – transfer of stock between locations; the workbook carries STN In, STN Out and STN Pending.
OE BO / Company BOBack order held at the OEM (company) against a dealer order.
OE In-Transit / POITPurchase-order quantity dispatched by the company and in transit to the dealer (workbook: POIT – Pending Purchase Orders In Transit).
CBOCustomer Back Order – quantity owed to a dealer's customer; added to SOQ.
Co-Dlr in TransitMaterial in transit from a co-dealer (gainer dealer) transaction.
Order FeedbackUpload of what was actually placed on the company against a Sparecare order: PO number, part number, alternate part, placed quantity. It also carries the dealer's response to the suggested order, part by part - ordered, not ordered and why, or a different quantity - which is used when the next order is prepared (workbook row 18; S07 08:48-13:37).
BDLBrand / Dealer / Location – the three levels at which a rule setting can be applied; default is Brand level.
Mother / Child / Single locationLocation roles within a dealership hierarchy used by the ordering rules; a Mother location orders on behalf of attached Child locations.
Ordering (placing) locationThe location (X) from which company orders are placed on behalf of other branches of the same dealership.
Excess (location)Excess at a partner location in inter-location case (b): Current Stock - MAX - Norm (Tables sheet row 74; S05 27:33-30:06; Section 6.5).
Cancellable OOQPending company orders that are not counted as OOQ because, under defined conditions, the company will not supply them (S05 31:42-35:30; workbook row 11).
EV / other-than-EV partsPart families used in the case (b) example: EV parts can be ordered from the company only by some locations; other-than-EV parts by all (S05 21:03-31:03).
TOC partsParts that the company (OEM) replenishes to a dealer location automatically, so the dealer does not order them; listed per dealer location (Tables sheet row 83: 250 TOC parts defined, ordered automatically by the company; 2,000 other parts to be generated). JCB calls its equivalent a "PASS order" (S06 11:12-13:55). The full form of TOC was not stated - see OI-038.
IndentA request from a child location to its mother location for stock - the child's own list of what it needs the mother to obtain for it (S06 29:07).
Pending ITO listThe list of internal transfer orders (stock transfers between a dealer's own locations) raised but not yet completed; some brands provide it as data (Maruti given as the example), others do not (S06 30:39; workbook row 15).
Excess stock at childStock at a child location above what it needs: Free Stock - MAX - buffer days of stock to be kept at the child (an input) (workbook row 16; S07 01:43).
Procurement optionsThe sources an order can be met from, in a set sequence: within the dealership's own branches (internal transfer, ITO), co-dealers (gainer), and the company (OEM) (Tables sheet rows 92-97; workbook row 21; S07 20:21).
Order outputWhat a dealer receives with a generated order: an e-mail with a summary and a download link or Excel file with the order to the company, internal transfer lines, orders pending from the company and customer back orders (S08 01:50-11:21).
Family partAn alternate part number for the same item; shown against each order line so the dealer can refer to it when the original part is short (S08 06:29-07:06).
Scheduled / non-scheduled orderA scheduled order is due on a dealer's ordering day and appears automatically in the day's list; a non-scheduled order is built on demand by filtering dealers, category and order type (S08 21:54-33:55).
Runner / Repeater / StrangerOrder-category summary shown per order on the current Sparecare order screen (count / value / a ratio for each category); the definitions were not given (OI-046).
Variance stock listA list of parts whose stock in the dealer's system is known to be wrong, with the plus or minus difference, uploaded so that the order is calculated on the corrected stock (S09 02:20-04:03; workbook row 33).
Ad hoc orderAn order built outside the schedule, typically to reach a target value; increase / decrease rules decide which parts get more or less quantity (S09 04:03-07:25; workbook row 34).
Editable / non-editable orderThe two parts an order is split into: non-editable lines the dealer places as they are, and editable lines (high CBO, MOQ, order value or unit cost) on which the dealer decides the quantity (S09 17:42-21:37; workbook row 24).
